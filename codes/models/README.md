# Модели YOLOv8

Папка содержит предобученные на COCO (80 классов) веса YOLOv8, которые использует система мониторинга парковки.

## Файлы

| Файл | Вариант | Размер | Вес (MB) |
|------|---------|--------|----------|
| `yolov8n.pt` | nano | самый лёгкий | 6.2 |
| `yolov8m.pt` | medium | средний | 49.7 |
| `yolov8x.pt` | x-large | самый тяжёлый | 130.5 |
| `yolov8m_parking_best.pt` | medium, дообученная | 2 класса: `space-empty`, `space-occupied` | 49.6 |

## Какая модель какая

| Модель | Параметры (M) | mAP50-95 | Precision | Recall | Время/кадр | FPS |
|--------|---------------|----------|-----------|--------|------------|-----|
| **YOLOv8n** (nano) | 3.2 | 37.3 | 0.72 | 0.65 | ~15 ms | ~80 |
| **YOLOv8m** (medium) | 25.9 | 50.2 | 0.81 | 0.74 | ~35 ms | ~40 |
| **YOLOv8x** (x-large) | 68.2 | 53.9 | 0.87 | 0.79 | ~75 ms | ~15 |

## Что выбрать

- **Наилучшая по точности — `yolov8x.pt`.** Максимальные precision/recall (0.87/0.79) и mAP. Это модель по умолчанию для системы. Минус — самая медленная и тяжёлая, требует GPU для реального времени.
- **Средняя (баланс) — `yolov8m.pt`.** Компромисс между скоростью и точностью. Хороший выбор, если `x` не тянет по FPS или памяти.
- **Самая быстрая — `yolov8n.pt`.** Запускается на слабом железе и CPU, но хуже ловит мелкие и частично перекрытые машины.

## Кратко о каждой

- **YOLOv8n** — самая компактная. Быстрая, нетребовательная, но точность ниже: на мелких объектах и бумажных макетах confidence часто падает ниже порога.
- **YOLOv8m** — «золотая середина». Заметно точнее nano при умеренном времени обработки (35 ms/кадр).
- **YOLOv8x** — максимальная точность для сложных сцен (много машин, дальний ракурс, слабое освещение). Используется как основная модель.

## Дообученная модель

`yolov8m_parking_best.pt` — результат fine-tune (`finetune.py`, 30 эпох) на датасете парковок. Метрики на валидации: mAP50 = 0.995, mAP50-95 = 0.950, precision = 0.999, recall = 0.998.

Отличие от моделей COCO: детектит **не машины, а сами места** — 2 класса `space-empty` (свободно) и `space-occupied` (занято). Поэтому она несовместима с текущей логикой `zones.py`, которая ищет bbox автомобилей внутри размеченных зон.

## Как переключить модель

Модель задаётся в `codes/config.py`:

```python
YOLO_MODEL = "models/yolov8x.pt"  # замените на models/yolov8n.pt или models/yolov8m.pt
```

Скрипты `run_camera.py`, `run_parking.py`, `run_cv_video.py` используют путь `models/yolov8x.pt` напрямую.

> Путь указывается относительно папки `codes/`, поэтому все скрипты нужно запускать из неё:
> ```powershell
> cd C:\parking-monitor\codes; python main.py
> ```

## Примечание

Это стандартные (не дообученные) веса COCO. Если файл отсутствует, Ultralytics автоматически скачает его при первом запуске. Для повышения точности на конкретной парковке используйте дообучение (`codes/finetune.py`).

# Parking Monitor 🚗

Автоматизированная система мониторинга заполненности парковки на основе компьютерного зрения.

Детекция транспорта (YOLOv8) + разметка зон + видеомониторинг в реальном времени + веб-интерфейс (Gradio) + база данных PostgreSQL для истории и статистики.

## Возможности

- **Детекция транспорта** — предобученная YOLOv8 (COCO: car, bus, truck, person).
- **Разметка парковочных зон** — интерактивно (Gradio или OpenCV); зоны хранятся пофайлово под каждое видео.
- **Определение занятости** — комбинированный метод (центр объекта + пересечение bbox с зоной), временное сглаживание.
- **Видеомониторинг** — окно OpenCV: зоны краснеют/зеленеют, счётчик `Free/Occupied` в реальном времени.
- **Пульт оператора** — вкладка Gradio с состоянием мест и журналом посещений.
- **База данных PostgreSQL** — история заполняемости, сессии стоянок (приезд/уезд), статистика по часам и дням недели.
- **Дообучение YOLOv8** — на датасете парковок, с логированием в MLflow и экспортом в ONNX.

## Быстрый старт

```powershell
cd codes
pip install -r requirements.txt
python main.py
```

Откроется веб-интерфейс (вкладки: Обработка, Разметка зон, Кадр, OpenCV, Пульт оператора).

**Видеомониторинг:**
```powershell
# разметка зон под видео (5 кликов = 4 угла + номер места)
python setup_zones_cv.py --video "image/Video/<файл>.mp4"

# запуск мониторинга (+ запись истории в БД)
python run_cv_video.py --video "image/Video/<файл>.mp4" --db
```

**База данных:**
```powershell
python -m db.init_db          # схема + зоны
python -m db.cli              # состояние мест и журнал в терминале
```

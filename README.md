# Parking Monitor - Автоматизированная система слежения за заполненностью автопарковки

## Описание
Система отслеживания заполненности парковочных мест (8 мест) с использованием YOLO и веб-камеры. Веб-интерфейс через Streamlit/Gradio.

## Чек-лист реализации

### 1. Подготовка окружения
- [ ] Создать структуру проекта
- [ ] Установить зависимости (ultralytics, streamlit/gradio, numpy, Pillow)
- [ ] Настроить virtual environment

### 2. YOLO детекция
- [ ] Подключить предобученную YOLOv8 (класс `car`)
- [ ] Протестировать детекцию на тестовых изображениях
- [ ] Настроить confidence threshold

### 3. Определение парковочных мест
- [ ] Задать координаты 8 парковочных зон
- [ ] Визуализировать зоны на кадре (Pillow/numpy)
- [ ] Сохранить конфигурацию зон в JSON

### 4. Логика определения занятости
- [ ] Алгоритм проверки: если bbox авто пересекает зону > N% → место занято
- [ ] Подсчёт занятых/свободных мест
- [ ] Обработка ложных срабатываний (сглаживание по кадрам)

### 5. Веб-интерфейс (Gradio)
- [ ] Захват видео с веб-камеры (`gr.Video(streaming=True)`)
- [ ] Отображение видеопотока с отрисовкой зон
- [ ] Отрисовка зон (зелёный = свободно, красный = занято)
- [ ] Вывод счётчика: `Свободно: X / 8`, `Занято: Y / 8`
- [ ] Кнопка старта/остановки

### 6. Тестирование
- [ ] Тест на напечатанном рисунке парковки
- [ ] Проверка точности детекции при разном освещении
- [ ] Стресс-тест (длительная работа)

### 7. Оптимизация (опционально)
- [ ] Ускорение инференса (YOLOv8nano, FP16)
- [ ] Настройка под реальную камеру

### 8. База данных (отложено)
- [ ] Логирование заполненности по времени
- [ ] Статистика и графики

## Структура проекта
```
C:\parking-monitor\

├── config.py            # Конфигурация (зоны парковки, пороги)
├── parking_zones.json   # Координаты парковочных мест
├── detector.py          # Обёртка над YOLO
├── requirements.txt     # Зависимости
├── README.md            # Этот файл
└── assets/              # Тестовые изображения, демо
```

```bash
pip install -r requirements.txt
python main.py
```

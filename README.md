# Parking Monitor 🚗

Система мониторинга заполненности парковки на базе **YOLOv8** с веб-интерфейсом **Gradio** и интерактивной разметкой зон.

## Как это работает

### 1. Детекция объектов
**YOLOv8** находит все машины на кадре. Используется предобученная модель (`yolov8n.pt` / `yolov8m.pt` / `yolov8x.pt`), которая детектит 80 классов COCO (car, bus, truck и т.д.). Настройки модели в `config.py`.

### 2. Зоны парковки
Каждое парковочное место — это полигон (прямоугольник или параллелограмм), заданный 4 точками. Зоны хранятся в `parking_zones.json` в формате:
```json
{"zones": [{"type": "poly", "points": [[x1,y1], ...], "label_x": cx, "label_y": cy}]}
```

### 3. Определение занятости
Для каждой зоны проверяется: находится ли **центр** bbox'а объекта внутри полигона зоны? Или пересекаются ли **углы/стороны** bbox'а с зоной. Если да — место **занято (красный)**. Если нет — **свободно (зелёный)**. Логика в `zones.py:update_states_by_center()`.

### 4. Визуализация
На кадре рисуются зоны с цветовой индикацией, отображаются bbox'ы распознанных машин и выводится счётчик свободных/занятых мест.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Откроется веб-интерфейс Gradio с вкладками:

| Вкладка | Назначение |
|---------|-----------|
| **📸 Обработка** | Загрузить фото парковки — получить разметку зон и счёт |
| **📐 Разметка зон** | Нарисовать зоны вручную: 5 кликов = 4 угла + номер места |
| **🖼️ Кадр** | Извлечь первый кадр из видео для разметки |
| **🎬 OpenCV** | Запустить обработку видео в отдельном окне OpenCV |

## Файлы проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | Gradio UI с вкладками обработки и разметки |
| `config.py` | Параметры: модель YOLO, пороги, типы |
| `detector.py` | Обёртка над YOLO: `detect()` и `detect_with_tracking()` |
| `zones.py` | Класс `ParkingZones`: загрузка, сохранение, проверка занятости, отрисовка |
| `parking_zones.json` | Координаты размеченных парковочных зон |
| `run_parking.py` | Видео + трекинг + разметка мышью (OpenCV) |
| `run_camera.py` | Веб-камера + трекинг + разметка мышью (OpenCV) |
| `run_cv_video.py` | Видео с готовыми зонами из `parking_zones.json` (OpenCV) |
| `setup_zones.py` | Tkinter редактор зон с видео |
| `setup_zones_cv.py` | OpenCV редактор зон с видео |
| `extract_frame.py` | Извлечь первый кадр из видео в `parking_frame.jpg` |
| `finetune.py` | Fine-tune YOLOv8 на датасете парковок (с MLflow) |

## Технологии
- Python 3.8+, Ultralytics YOLOv8, Gradio, OpenCV, Pillow, NumPy, MLflow (опционально)
